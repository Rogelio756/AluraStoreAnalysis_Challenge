# 📊 Análisis de las Tiendas Alura Store

Este proyecto consiste en un análisis de datos de las tiendas Alura Store para ayudar en la toma de decisiones sobre la venta de una de las tiendas. Se analizan datos de ventas, rendimiento y reseñas de clientes.

## Desafío

El objetivo principal es proporcionar al Sr. Juan una recomendación sobre qué tienda de su cadena Alura Store debería vender para iniciar un nuevo emprendimiento.

## Requisitos

* Análisis de datos de:
    * Ingresos 💰
    * Categorías más vendidas 📈
    * Reseñas de clientes ⭐
    * Productos más vendidos 🏆
    * Tiempo promedio de envío 🚚
* Visualización de resultados mediante gráficos de barras 📊, circulares  pie chart 🥧 y de dispersión 📈.
* Recomendación final con justificación basada en los datos.

## Estructura del proyecto

El proyecto se desarrolla en un notebook de GoogleColab (AluraStoreLatam.ipynb) 📓 que contiene el análisis de datos y la visualización de los resultados.

## Dependencias

* Python 3 🐍
* Pandas 🐼
* Matplotlib 📊
* Seaborn 🌊
* Plotly 📈

## Instalación

1.  Asegúrate de tener Python 3 instalado en tu sistema.
2.  Instala las dependencias usando pip:

    ```bash
    pip install -r requirements.txt
    ```
3.  Ejecuta el notebook `AluraStoreLatam.ipynb` para realizar el análisis.

## Uso

El notebook `AluraStoreLatam.ipynb` contiene el código y las explicaciones necesarias para realizar el análisis de datos y generar las visualizaciones. Simplemente ejecuta las celdas en orden para obtener los resultados y la recomendación final.

## Resultados

El análisis proporciona información sobre la facturación por tienda 💰, las categorías más vendidas 📈, la calificación promedio de las tiendas ⭐ y la distribución de ingresos por venta.

## Recomendación

La recomendación final se encuentra detallada en la sección de conclusión del notebook. Se sugiere considerar la venta de la tienda 4 debido a su bajo rendimiento en comparación con las demás.
