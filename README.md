# 📊 Análisis de Tiendas - Alura Store Latam

Este proyecto tiene como objetivo ayudar al Sr. Juan a decidir cuál de sus tiendas de la cadena **Alura Store** debería vender, con base en un análisis detallado de datos de ventas, reseñas de clientes y tiempos de entrega.
